How It Works

Three commands.
Zero configuration.

From install to protected in under a minute.

1

Initialize

Scaffolds AGENTS.md, git hooks, IDE rules, and MCP config into your project.

npx soloknuckle init
2

Check

Runs 10 hygiene dimensions. Shows human-friendly report with scores, issues, and fix suggestions.

npx soloknuckle check
3

Fix

Auto-fixes lint issues, missing tests, git init, CI workflows, .gitignore, feature flags, and docs.

npx soloknuckle check --fix

Security

Privacy-first by design.

Your code never leaves your machine. Ever.

🏠 Local Only

All data stays in ~/.soloknuckle/. Nothing sent to external services. Zero telemetry.

🔐 No PII Collection

No names, emails, or usage data collected. Your identity is nobody's business.

📦 npm Provenance

Every publish is cryptographically tied to the source commit via OIDC. Verify the package came from this repo.

🚫 No Automated Publishing

All releases are manual. No CI tokens that could be stolen. 2FA required with hardware security key.

🔍 Supply Chain Safe

ignore-scripts=true blocks malicious install scripts. min-package-age=72h prevents typosquatting.

🛡️ Rate Limiting

CORS restricted to localhost. Body size limits prevent memory exhaustion. LLM endpoints protected.
