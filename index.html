Security

Privacy-first by design.

Your code never leaves your machine. Ever.

🏠 Local First

All data stays in ~/.soloknuckle/. No telemetry. Code is only sent to external services when you explicitly run LLM commands (audit, pr).

🔐 No PII Collection

No names, emails, or usage data collected. Your identity is nobody's business.

📦 npm Provenance

Every publish is cryptographically tied to the source commit via OIDC. Verify the package came from this repo.

🚫 No Automated Publishing

All releases are manual. No CI tokens that could be stolen. 2FA required with hardware security key.

🔍 Supply Chain Safe

ignore-scripts=true blocks malicious install scripts. min-package-age=72h prevents typosquatting.

🛡️ Rate Limiting

CORS restricted to localhost. Body size limits prevent memory exhaustion. LLM endpoints protected.
